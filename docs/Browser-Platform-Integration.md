# Browser controls on macOS and NEXTSPACE

**Follow** keeps the Mac approach. **Extend** adds NEXTSPACE behavior. The scrollbar work is to refine the existing native integration.

| Attribute | Chrome Mac | Chrome nextspace | Chrome UX | Firefox Mac | Firefox nextspace | Firefox UX |
| --- | --- | --- | --- | --- | --- | --- |
| Window, tabs, toolbar | Native window hosts Chrome's own Views controls. [Source](https://chromium.googlesource.com/chromium/src/+/main/docs/ui/input_event/index.md) | **Follow** | The window gets a NEXTSPACE title bar. | Cocoa window hosts Firefox's HTML/XUL interface. [Window](https://github.com/mozilla-firefox/firefox/blob/main/widget/cocoa/nsCocoaWindow.mm), [UI](https://github.com/mozilla-firefox/firefox/blob/main/browser/base/content/browser.xhtml) | **Follow** | The window gets a NEXTSPACE title bar. |
| Application menu | Native main menu runs Chrome commands. [Source](https://chromium.googlesource.com/chromium/src/+/main/chrome/browser/app_controller_mac.mm) | **Follow** | File opens in the desktop menu. | Native main menu runs Gecko commands. [Source](https://github.com/mozilla-firefox/firefox/blob/main/widget/cocoa/nsMenuBarX.mm) | **Follow** | Bookmarks opens in the desktop menu. |
| Context menus and dropdowns | Selected Views menus and HTML select popups use native menus. [Context](https://chromium.googlesource.com/chromium/src/+/cec9a057ab0f005a267cbb4d78fcd363d07738ac/ui/views/controls/menu/menu_runner_impl_cocoa.mm), [Select](https://github.com/chromium/chromium/blob/main/content/browser/renderer_host/popup_menu_helper_mac.mm) | **Follow** | Right-clicking a webpage link opens a native menu. | Gecko uses native context menus and supported anchored popups. [Source](https://bugzilla.mozilla.org/show_bug.cgi?id=1710459) | **Follow** | Right-clicking a webpage link opens a native menu. |
| Scrollbars | Blink draws scrollbars using Mac metrics and preferences. [Drawing](https://github.com/chromium/chromium/blob/main/third_party/blink/renderer/core/scroll/scrollbar_theme_mac.cc), [Settings](https://github.com/chromium/chromium/blob/main/content/browser/theme_helper_mac.mm) | **Extend** | Webpages use the native left-side GNUstep scrollbar with arrows. | Gecko draws Cocoa-style scrollbars and owns scrolling. [Source](https://github.com/mozilla-firefox/firefox/blob/main/widget/ScrollbarDrawingCocoa.cpp) | **Extend** | Webpages use the native left-side GNUstep scrollbar with arrows. |
| Form controls | Blink retains control state and uses its theme painter with Mac appearance settings. [Painting](https://github.com/chromium/chromium/blob/main/third_party/blink/renderer/core/paint/theme_painter_default.cc), [Mac appearance](https://github.com/chromium/chromium/blob/main/third_party/blink/renderer/core/layout/layout_theme_mac.mm) | **Follow** | A checkbox is still drawn by Chrome. | Gecko draws selected controls with Cocoa cells and supplies its own drawing for others. [Source](https://github.com/mozilla-firefox/firefox/blob/main/widget/cocoa/nsNativeThemeCocoa.mm) | **Follow** | An eligible button gets a GNUstep border and face. |
| File dialogs | AppKit open and save panels return results to Chrome. [Source](https://chromium.googlesource.com/chromium/src/+/main/components/remote_cocoa/app_shim/select_file_dialog_bridge.mm) | **Follow** | Uploading a file opens a native GNUstep panel. | AppKit open and save panels return results to Firefox. [Source](https://github.com/mozilla-firefox/firefox/blob/main/widget/cocoa/nsFilePicker.mm) | **Follow** | Uploading a file opens a native GNUstep panel. |
| Color and calendar pickers | Blink supplies browser-rendered color and date/time popups. [Color](https://github.com/chromium/chromium/blob/main/third_party/blink/renderer/core/html/forms/color_chooser_popup_ui_controller.cc), [Date/time](https://github.com/chromium/chromium/blob/main/third_party/blink/renderer/core/html/forms/date_time_chooser_impl.cc) | **Follow** | A color field opens Chrome’s picker. | Firefox uses the native color panel and its own date/time picker. [Color](https://github.com/mozilla-firefox/firefox/blob/main/widget/cocoa/nsColorPicker.mm), [Date/time](https://github.com/mozilla-firefox/firefox/blob/main/toolkit/actors/DateTimePickerParent.sys.mjs) | **Follow** | A date field opens Firefox’s calendar. |
| Application shortcuts | Native menu key equivalents and Chrome accelerators run actions such as New Tab. [Source](https://chromium.googlesource.com/chromium/src/+/lkgr/chrome/browser/global_keyboard_shortcuts_mac.mm) | **Follow** | Alt+T opens a tab when bound to New Tab. | Native menu key equivalents run Firefox commands. [Source](https://github.com/mozilla-firefox/firefox/blob/main/widget/cocoa/nsMenuBarX.mm) | **Follow** | Alt+T opens a tab when bound to New Tab. |
| Text editing, undo, clipboard and IME | Cocoa interprets text input and edit commands. Chromium owns its editor. [Source](https://chromium.googlesource.com/chromium/src/+/main/docs/ui/input_event/index.md) | **Follow** | Alt+A selects the address when bound to Select All. | Cocoa key bindings map to Gecko edit commands. Gecko retains the editor and IME integration. [Bindings](https://github.com/mozilla-firefox/firefox/blob/main/widget/cocoa/NativeKeyBindings.mm), [IME](https://firefox-source-docs.mozilla.org/editor/IMEHandlingGuide.html) | **Follow** | Alt+A selects field text when bound to Select All. |
| Built-in pages | Settings and other WebUI pages use Chrome's shared components. [Source](https://chromium.googlesource.com/chromium/src/+/HEAD/ui/webui/resources/cr_elements/) | **Follow** | Settings keeps Chrome’s toggle shapes. | Firefox uses shared HTML/XUL widgets. [Source](https://firefox-source-docs.mozilla.org/browser/components/storybook/docs/README.reusable-widgets.stories.html) | **Follow** | Settings keeps Firefox’s toggle shapes. |
| DevTools | The console uses CodeMirror and shared frontend styling. [Source](https://github.com/ChromeDevTools/devtools-frontend/blob/main/front_end/panels/console/ConsolePrompt.ts) | **Follow** | The console keeps its original code editor. | Firefox wraps CodeMirror and keeps editor-owned undo. [Source](https://github.com/mozilla-firefox/firefox/blob/main/devtools/client/shared/sourceeditor/editor.js) | **Follow** | The console keeps its original code editor. |
