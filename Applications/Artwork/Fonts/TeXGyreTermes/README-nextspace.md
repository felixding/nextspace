# Artwork lettering sources

The unmodified TeX Gyre Termes Regular and Bold Italic 2.004 fonts are by Boguslaw Jackowski
and Janusz M. Nowacki, based on URW Nimbus Roman No9 L. Its original readme,
manifest, GUST Font License and LPPL 1.3c accompany the font.

Source: https://ctan.org/pkg/tex-gyre-termes
Font: https://mirrors.ctan.org/fonts/tex-gyre/opentype/texgyretermes-bolditalic.otf
Font: https://mirrors.ctan.org/fonts/tex-gyre/opentype/texgyretermes-regular.otf

Seven Bold Italic glyph outlines are used in TextEdit's SVG title. Their placement,
vertical proportions, i-dot position and layered shadow are adjusted to the
original low-resolution title. This is lettering artwork, not a modified font
distribution. The native build renders the embedded paths without loading a
font or depending on Ghostscript. Review's five document labels use ten Regular
glyph outlines, with sizes and spacing matched to the original serif labels.
These are compatible replacement outlines; the original font file was not
recovered from the low-resolution artwork.

Documents.svg uses a fitted Regular question-mark hook with adjusted lower-stem
curves and a separately drawn rounded-square period to retain the original
document icon's ink weight, shape and placement. The font itself is unchanged.
