# TeX Gyre Heros artwork reference

This directory retains the unmodified TeX Gyre Heros 2.004 regular face by
Boguslaw Jackowski and Janusz M. Nowacki, its upstream readme/manifest and the
GUST Font License/LPPL text. The upstream package contains additional faces;
NEXTSPACE retains only the regular face used to author the color-picker heading.

The five NAMED outlines in `Libraries/gnustep/Artwork.svg` are fitted to the
pinned GNUstep original. This does not establish the original font's identity.
The SVG contains the contours, so rendering the artwork has no font dependency.
