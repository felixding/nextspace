# NeXTSpirit source artwork

These are the complete, unmodified first and second NeXTSpirit Retina icon
sets by Gael Elegoet (galgot), including both original readmes. Exact source
pages, archive checksums and all fifty file checksums are recorded in
`../NextSpirit.json`. Keep the complete sets and original readmes together.

The original readmes permit personal, noncommercial use. Current builds with
these sources are local personal builds; unrestricted release permission has
not been established. See `docs/Artwork-Sources.md` for the verified mappings.

The native build selects the original 1024-pixel artwork directly for each
backing density and preserves each existing logical size. It uses constructed
original-style geometry only for designs missing from these collections.
