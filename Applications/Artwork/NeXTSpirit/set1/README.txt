I fell in love with the NeXTSTEP/OPENSTEP system icons, for their retro/realistic look.
Here is a Mac OSX icons set completely inspired by the work of Susan Kare and keith Ohlfs for these Systems. All credit to them.
The PReV icon was kindly adopted by the developers of the Previous emulator :
http://previous.alternative-system.com
The one included in this pack is another version with different fonts.
Most icons modeled and rendered (Cycles) in Blender 2.70, post in Photoshop. Only the Mail icon completely done in photoshop.

For non-commercial and only personal use of course.
Feel free to redistribute, but if so, please leave the set complete together with this Readme. Thanks.
