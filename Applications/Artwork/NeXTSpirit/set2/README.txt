This is my second NeXTSpirit OS X icon set. This time focused on OS X system folders and few apps, most of the icons are adaptations of NeXTStep icons to a modern OS X system, that just never existed in NeXTStep. Others are hires versions of existing NeXTStep icons, like  Librarian app that can be used for the Library folder in OS X, or the Grab app camera can be used for the preview app in OS X…
Also all done in Blender 2.70, postwork in Photoshop.
