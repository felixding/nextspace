# Original slider knobs

The TIFFs match the pinned GNUstep GUI image archive byte for byte. The PNGs
are the RGB representations selected by the native Wayland probe. Horizontal
and vertical logical sizes are 19 by 14 and 14 by 19 points. The shared LGPL
text is [COPYING.LIB](../color-panel/COPYING.LIB).

The SVG preserves the distinct bevel corners and grip orientation of each
original. It uses structural paths and rectangles with continuous grip lighting.
